MCP Tools

These tools call the shared Faculty Management System MCP server through the Teaching, Subject & Classroom Allocation backend.

Check Classroom Availability

Checks whether a classroom is free for a specified date and time without creating or modifying allocation data.

Validate Teaching Allocation

Validates a proposed teaching allocation using the existing subject, classroom, scheduling and staff rules. No teaching allocation is created or modified.

Optional. Leave unassigned if no staff member should be validated.

RAG Tools

The shared Retrieval-Augmented Generation service retrieves grounded Faculty Management System context before generating answers. Responses include citations and a confidence category.

Refresh Shared Corpus

Rebuilds the shared RAG corpus from the current feature data.

Retrieve Context

Retrieves the most relevant corpus chunks without asking the language model to generate an answer.

Ask Grounded Question

Retrieves relevant evidence and sends only that context to the local language model. The answer includes its retrieved citations and confidence category.
