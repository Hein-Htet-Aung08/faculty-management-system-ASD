MCP Mode

Exercises the same 4 tools as the standalone mcp-server/, over plain HTTP, gated behind this toggle. Turning it off proves the tools genuinely refuse to run rather than just hiding the buttons.

staff_count

Total number of staff with a workload profile.

staff_by_status

Staff filtered by workload status.

project_files

Lists files/folders under student-3Tristan-Lim/, relative to that directory.

ci_report

Reads the CI evidence report generated by student-3-TristanLim.yml.
