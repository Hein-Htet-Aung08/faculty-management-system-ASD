RAG Mode

Refreshes the corpus from live staff workload data, retrieves relevant chunks by vector similarity, and answers questions grounded only in what was retrieved - with citations and a confidence category. Gated behind this toggle, same as MCP Mode.

refresh_corpus

Rebuilds the corpus and vector index from staff workload data, CI reports, and a repository file listing.

retrieve_context

Retrieves the top-k chunks most relevant to a query.

answer_question

Answers a question using only retrieved evidence, with citations and a confidence category.
